# MCWIN31 Firmware Binaries

This folder is reserved for MCWIN31 release binaries. Stale upstream SlopOS binaries were removed so users do not accidentally flash the wrong firmware.

Build artifacts are generated by PlatformIO:

```powershell
pio run -e MCWIN31_TDeck
```

Expected outputs:

| File | Use |
|------|-----|
| `.pio/build/MCWIN31_TDeck/firmware.bin` | App update at `0x10000` |
| `.pio/build/MCWIN31_TDeck/firmware-merged.bin` | Full flash at `0x0` |
| `webflasher/mcwin31-tdeck-*.bin` | Web flasher artifacts |
| `webflasher/manifest.json` | Web flasher manifest |

Flash the merged binary only when intentionally replacing the whole flash image.
